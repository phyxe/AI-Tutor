# AI-Tutor

Instruction files for AI-guided learning activities organized by learning area.

## Practical Research 2 (PR2)

- [Shared PR2 AI standards](pr2/pr2-ai-standards.md)
- [Activity 01 (`pr_act_01`): Quantitative Research Topic Declaration](pr2/activities/pr2-ai-a01-research-declaration.md)
- [Activity 02 (`pr_act_02`): Individual Chapter 1 Research Foundation](pr2/activities/pr2-ai-a02-chapter-1.md)
- [Approved-outcome sample (`pr2_pru_00`)](pr2/approved/pr2_pru_00.md)

Each student starts one new ChatGPT conversation per activity. The AI must retrieve and verify the shared standards and assigned activity file, plus the student's teacher-approved outcome file when that activity requires one, before starting. When a file cannot be read completely, the AI must stop and direct the student to contact the teacher.

These files are drafts for teacher testing. They do not authorize participant recruitment, data collection, or independent changes to official assessment requirements.
