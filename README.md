# AI-Tutor

Instruction files for AI-guided learning activities organized by learning area.

## Practical Research 2 (PR2)

- [Shared PR2 AI standards](pr2/pr2-ai-standards.md)
- [Activity 01: Quantitative Research Topic Declaration](pr2/activities/pr2-ai-a01-research-declaration.md)

Each student starts one new ChatGPT conversation per activity. The AI must retrieve and verify the complete text of the two linked instructions before starting. When a file cannot be read completely, the AI must stop and direct the student to contact the teacher.

These files are drafts for teacher testing. They do not authorize participant recruitment, data collection, or independent changes to official assessment requirements.
