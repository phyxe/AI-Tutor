## Activity 01 student starter prompt

> Read and follow these two PR2 instruction files completely: https://raw.githubusercontent.com/phyxe/AI-Tutor/main/pr2/pr2-ai-standards.md and https://raw.githubusercontent.com/phyxe/AI-Tutor/main/pr2/activities/pr2-ai-a01-research-declaration.md.
>
> If either file is inaccessible or cannot be read completely, stop and instruct me to contact my teacher.

The deadline, interaction rules, ten approximate checkpoints, and final submission requirements are contained in the two instruction files, not in the starter prompt.

**Start-of-activity test:** After a student replies `English` to the language-choice question, the AI must ask `What concern or research idea would you like to investigate?` in the **very next response**. An acknowledgment or "Let's begin" message alone is not sufficient.

When testing in ChatGPT Free, verify that the full file content was read instead of inferring access from a filename, a preview, or a search snippet. GitHub hosting does not guarantee every ChatGPT retrieval attempt will succeed.

## Activity 02 student starter prompt (three URLs)

The teacher must first create and publish the **individual teacher-approved concept file** with a unique non-identifying code and an explicit **Approved for Chapter 1 drafting** status. Do not give students the placeholder prompt as-is.

> Read and follow these three PR2 documents completely:
> 1. https://raw.githubusercontent.com/phyxe/AI-Tutor/main/pr2/pr2-ai-standards.md
> 2. https://raw.githubusercontent.com/phyxe/AI-Tutor/main/pr2/activities/pr2-ai-a02-chapter-1.md
> 3. [EXACT TEACHER-PROVIDED APPROVED-CONCEPT URL]
>
> My teacher-provided concept code is [CODE MATCHING FILE].
> Use the research details and teacher conditions from the third URL, not guessed data or past chat memory. If any file cannot be read completely, the code or approval does not match, or the concept is not approved, stop and instruct me to contact my teacher. Otherwise, begin Activity 02.

For Activity 02, do not use a student's name or section as a public lookup key. The exact third URL is required. The activity file controls the two-source process, LM05–LM07 tasks, full student-response evidence, ZIP/Markdown packaging, and **approximate start and readiness-to-compile end timestamps**. Time values must be verified or honestly marked unverified; wall-clock duration is not active work time.

**Activity 02 test:** Verify all three files are actually readable in ChatGPT Free. After language selection, the next reply must ask an actionable question about the loaded concept's real-life context. The approved-concept files are a separate teacher publication step and are not automatically generated by this activity file.
