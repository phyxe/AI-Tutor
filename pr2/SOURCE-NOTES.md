## Review scenarios

| Input condition | Required controller behavior |
|---|---|
| Brief but sufficient answer | Proceed without demanding full sentences |
| “Stress” offered without an activity-required indicator | Ask for the missing observable/rateable focus; do not invent one |
| Association claimed to prove causation | Name the overclaim and elicit a defensible correction |
| Copied model topic | Elicit student reasoning/application; do not mark independent mastery |
| Recoverable issue explicitly allowed by activity | Carry forward with a named repair point; do not waive completion |
| One mandatory completion criterion missing | No `.phx` and no full submission-record fallback |
| Future permission pending outside a completed planning activity's gate | May compile the planning activity, without implying fieldwork approval |
| Required activity approval pending | Stop dependent progression and submission; name teacher decision needed |
| Current activity complete with a mapped next activity | Compile current `.phx`; provide new-chat handoff without starting next activity |

These are review expectations, not executed ChatGPT behavioral test results. Target-access and classroom release testing remain pending.
