# Effective Communication student outcomes

This folder is reserved for teacher-issued coded outcome files. No students or activities are assigned yet. The blank template is not a student record or authorization.

Store only minimal, teacher-reviewed, non-identifying summaries suitable for public access. Keep identity mappings, private drafts, detailed feedback, transcripts, and assessment records outside the public repository.

Future activity records must distinguish student report, tutor-observed evidence, teacher verification, task-specific AI permission, and explicit routing. Do not copy the PR2 activity codes or default route. A generated progress draft does not update GitHub.
