## Scenario review and practical limits

The current rule paths were reviewed for these cases:

1. Sufficient prior work: retain evidence, skip satisfied core prompts and do not start a compulsory interview.
2. Partial/wrong answer: name the issue, teach briefly and elicit application within the shared allowance; no filled target answer or choices.
3. Follow-up exhaustion: stop repairs, collect any genuinely unasked core prompts, then submit an honest incomplete record. No new budget through another chat, rephrased questions or a hidden batch.
4. Teacher-authorized Activity 2 with Activity 1 clarification: execute destination work, record the earlier clarification at its mapped target, and submit both; no duplicate approval cycle.
5. Same-activity revision: preserve old/new work and change evidence; repair only named/affected targets, then submit for later decision.
6. Locked-decision alternative: preserve the approved baseline and record the proposal/rationale without treating it as accepted; continue independent authorized work.
7. File tools unavailable: generate the actual accepted chat report instead of only explaining failure; no invented downloadable file or required manual file construction.
8. Updating mid-chat: save if possible, give short download/return instructions and pause. Student return phrase triggers a live status recheck, not release. Resume directly to the next task only on verified release.
9. Standalone PR2/EFFCOM review: preserve its own learning requirements, assistance permissions and completion-only endpoint; shared chat delivery does not import production budgets or weaken the gate.
10. Missing history/unknown follow-up count: disclose unavailable evidence/counts and do not invent a reset or transcript. Missing authority blocks only dependent work; use permitted evidence collection and teacher diagnostic.

These are editorial scenario checks, not live model conversations or end-to-end artifact generation tests. Classroom tests still need to inspect actual questioning, status access, source understanding, file/chat fidelity, baseline capture and resumed counters. Do not treat the smaller files as a compliance guarantee.
